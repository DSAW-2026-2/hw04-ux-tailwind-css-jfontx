# AI Log - HW04

## AI Use

AI was used as a support tool during HW04, mainly to review parts of the implementation and get suggestions for Tailwind CSS.

We used it to review the color palette, responsive layout, and the dark mode implementation with `localStorage`. It was also useful for checking the final consistency of the landing page with the PlayReal project.

The team reviewed the suggestions and decided what to keep or change in the final version.

## Tailwind Color Palette

AI suggested using a simple palette based on blue, green, amber, slate, and white.

The main colors used were:

- `blue-50`, `blue-100`, `blue-500`, `blue-600`, and `blue-700`
- `green-100` and `green-700`
- `amber-100` and `amber-700`
- `slate-50`, `slate-800`, `slate-900`, and `slate-950`
- `white`

We kept blue as the main PlayReal color.

Green was limited to positive states such as active status and streaks, while amber was used for time-related information. Slate colors were mainly used for neutral elements and dark mode.

## Implementation Review

AI was used to review the Tailwind utility classes, responsive behavior, and dark mode functionality.

The final landing page uses Tailwind CSS for styling and responsive design. JavaScript is only used for the dark mode toggle and to save the selected theme in `localStorage`.

The final code and design were reviewed and adjusted by the team before submission.
